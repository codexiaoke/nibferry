## 分隔线与控件轮廓

设计中分别使用 `border.divider`、`border.surface`、`border.input` 表达分隔线、表面边界和输入边框。浅色下三者可以同色；深色下输入边框比普通分隔线更清晰。当前 CSS 入口提供基础线色 `--nf-line`。

## 键盘焦点环

焦点环使用 2px 线宽和 2px 外偏移。通过 `:focus-visible` 显示键盘位置，让焦点在选中项或悬停项上也清晰可见。

```css
.trigger:focus-visible {
  outline: 2px solid var(--nf-accent);
  outline-offset: 2px;
}
```

## 阴影与遮罩

设计规范中的常规表面、浮层和对话框默认采用边框，可按各自用途覆盖完整投影。模态对话框另设背景遮罩，在遮罩上调节透明度，让面板文字保持清晰。普通下拉菜单沿用自己的底色和轮廓。
