## 安装组件库

在使用 React 19 和 React DOM 19 的应用中运行：

```sh
pnpm install nibferry
```

## 导入样式

在应用入口引入一次样式表，所有页面即可共用组件样式和默认主题变量。Next.js App Router 项目放在根布局 `app/layout.tsx`，Vite React 项目通常放在 `src/main.tsx`。

```ts
import 'nibferry/styles.css';
```

## 使用组件

```tsx
import { AssistantMessage } from 'nibferry';

export function Welcome() {
  return <AssistantMessage>你好，需要什么帮助？</AssistantMessage>;
}
```

在[组件总览](/docs/components)中查看其他组件的预览和用法。主题配置见[设计 Token](/docs/theme)。
