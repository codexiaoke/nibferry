# 设计 Token

从 `@nibferry/react/theme` 读取默认颜色、配色预设和动效参数。时长以毫秒表示，缓动曲线由四个三次贝塞尔参数组成。

```ts
import { palettes, theme } from '@nibferry/react/theme';

const primary = palettes.neutral.primary;
const feedbackMs = theme.motion.feedback;
```

## Web 样式

在应用入口导入默认 CSS 变量。组件或页面可以在自己的作用域内覆盖所需变量。

```ts
import '@nibferry/react/styles.css';
```

```css
body {
  color: var(--nf-ink);
  background: var(--nf-canvas);
}
```
