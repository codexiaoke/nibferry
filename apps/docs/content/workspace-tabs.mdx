## 组合标签栏

<TabsDemo />

`WorkspaceTabList` 和 `WorkspaceTab` 负责选择与排序。将 `WorkspaceTabAdd` 放在列表旁边，横向滚动时仍可新增。向标签传入 `onClose` 即可显示关闭按钮，也可以单独使用 `WorkspaceTabClose`。

```tsx
import { WorkspaceTabList, WorkspaceTab, WorkspaceTabAdd } from 'nibferry';

<WorkspaceTabList aria-label="文档标签" onReorder={setOrder}>
  {order.map(id => (
    <WorkspaceTab key={id} id={id} panelId={id + '-panel'} label={pages[id].title}
      selected={activeId === id} onClick={() => setActiveId(id)} onClose={() => closePage(id)} />
  ))}
</WorkspaceTabList>
<WorkspaceTabAdd onClick={addPage} />
```

每个标签使用稳定的 ID。拖到另一个标签上松开后，`onReorder` 返回完整的新顺序。活动页使用独立的 ID，以便调换位置时继续显示当前内容。

## 切换与关闭

触屏上横滑可浏览超出宽度的标签，按住标签片刻再拖动可排序。左右方向键、Home、End 切换标签，Alt 加左右方向键移动标签，Delete 关闭当前标签。接入方决定新页的内容和关闭后选中哪一页。为每个内容区设置 `role="tabpanel"` 及指向标签的 `aria-labelledby`。嵌入文档时可以按打开顺序挂载内容区，通过 `hidden` 切换显示，以保留文档的阅读位置。

在桌面预览中，点「新增标签页」后可以选择来源。再次打开同一文档会切换到已有标签，关闭最后一页会收起右侧工作区。[交互预览](/playground/)
