## 从左栏打开

<SearchDemo />

点击工作区名称右侧的放大镜。输入会话标题或项目名可找到聊天，输入文档标题或章节文字可打开对应资料。用底部分类缩小搜索范围。上下方向键移动高亮，Enter 打开结果，Esc 返回搜索入口。[桌面交互预览](/playground/)

## 配置搜索结果

`SearchDialog` 接收分组数据和每个结果的 `onSelect`。`detail` 显示在行尾，适合放项目名或来源。`previewLimit` 控制一组在「全部」初始视图中的条数，输入关键词后会匹配该分类的全部条目。

```tsx
import { SearchDialog } from 'nibferry';

<SearchDialog open={open} onOpenChange={setOpen} label="搜索工作区"
  groups={[
    { id: 'actions', label: '快捷操作', filterLabel: '操作', items: [
      { id: 'compose', label: '新聊天', shortcutKey: 'N', onSelect: newChat },
    ] },
    { id: 'chats', label: '聊天', previewLimit: 5, items: chats.map(chat => ({
      id: chat.id, label: chat.title, detail: chat.project, onSelect: () => openChat(chat.id),
    })) },
  ]} />
```

## 通用弹框

<DialogDemo />

需要自定义内容时，使用同一套基础组件 `Dialog`。它处理模态焦点、遮罩、Esc 和入场动效。接入方通过 `open` 与 `onOpenChange` 控制开合，并通过 `aria-label` 或 `aria-labelledby` 提供弹框名称。

```tsx
import { Dialog } from 'nibferry';

<Dialog open={editing} onOpenChange={setEditing} aria-label="编辑项目">
  <label>项目名称<input autoFocus value={name} onChange={e => setName(e.target.value)} /></label>
  <button onClick={saveProject}>保存</button>
</Dialog>
```
