## 快速开始

[接入项目](/docs/installation)介绍如何在本地运行官网、构建包，并在 React 项目里加载默认样式。

## 设计体系

- [**设计 Token** 读取主题与局部覆盖](/docs/theme)
- [**颜色与文字** 为表面、文字和主操作选择颜色](/docs/colors)
- [**边框与层级** 配置轮廓、焦点和弹层遮罩](/docs/surfaces)
- [**动效与过渡** 调整反馈时长和缓动曲线](/docs/motion)

## 在浏览器里试用

打开[交互预览](/#playground)，播放动效或切换配色。要查某个角色的实际导出值，可以直接进入 [Token 浏览器](/#tokens)。
