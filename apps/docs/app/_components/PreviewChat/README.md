# PreviewChat

输入框底栏左侧为操作菜单和权限，右侧为上下文用量、模型和语音控件。权限、模型和推理强度保存在当前会话预览里，用量为示例值。麦克风插入示例转写，空草稿时波形按钮可发送示例消息。

发送包含 `useState` 的消息会展示本地搜索与读取结果。搜索结果随组内列表滚动，来源链接显示在独立的回复正文中。

交互预览的会话内容示例。传入 `seeded` 显示一轮已完成的布局草图，`hidden` 随当前会话切换。点击布局文档或回复里的来源链接，`onOpenSource` 将标题和地址交给右侧工作区。布局草图与普通回复按本地定时器逐段到达，演示草稿、停止、分组与流内组件状态。
