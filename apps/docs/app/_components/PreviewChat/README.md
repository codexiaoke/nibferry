# PreviewChat

输入框底栏左侧为操作菜单和权限，右侧为上下文用量、模型和语音控件。权限、模型和推理强度保存在当前会话预览里，用量为示例值。点麦克风直接听写，结束录音后可编辑转写并发送。选中引文后也能听写追问。空草稿的波形菜单提供录音并发送及示例语音。

发送包含 `useState` 的消息会展示本地搜索与读取结果。搜索结果随组内列表滚动，来源链接显示在独立的回复正文中。

交互预览的会话内容示例。传入 `seeded` 显示一轮已完成的布局草图，`hidden` 随当前会话切换。点击布局文档或回复里的来源链接，`onOpenSource` 将标题和地址交给右侧工作区。布局草图与普通回复按本地定时器逐段到达，演示草稿、停止、分组与流内组件状态。

点击加号中的「添加文件」、把文件拖到聊天区任意位置或在输入框粘贴截图会将附件加入当前会话草稿。图片和 PDF 在右栏预览原件，DOCX 显示正文，文本按原文展示。点击同一附件会回到已有标签。文件和预览只在本地浏览器内存中保存，刷新页面后清空。演示支持只发送附件。

悬停用户消息可复制或编辑。编辑会取回文字和附件，取消或重新发送后恢复之前的输入框草稿。修改和重新生成会在选中的回合添加新版本。中断重试在当前版本继续。回复下方的操作包括复制、评价、浏览器朗读，以及更多菜单中的重新生成。

在浏览器开发者工具中切到离线，再发送消息即可查看发送失败。生成布局草图期间切到离线，可查看回复中断。恢复联网后点该条消息的重试按钮，继续演示。本地示例使用浏览器网络状态，接入实际服务时由宿主处理请求与流错误。

发送「展示 Markdown 排版」可试用列表、表格、代码复制和段落内引用。引用按文档路径复用右栏标签，每次点选都会定位到相应章节。发送「展示审批与画布」可在流式回复中操作审批、选择并重命名流程节点。两个示例也可以从交互预览的 `?example=markdown` 和 `?example=cards` 直接打开。

「设置 → 通用 → 回复动效」可切换像素显影、流光笔尖和只看文字，并重播样例。打开预览时也可设置查询参数 `effect=pixel`、`effect=pen` 或 `effect=plain`。混合回复中的流程图可以在右栏打开。

打开 `?example=chat` 可从短页历史开始验收。向上滚到顶部逐页加载历史消息。引用可以截取正文并跳回原版本。附件上传使用本地计时器模拟进度，离线时进入失败状态，每个文件可独立取消和重试。
