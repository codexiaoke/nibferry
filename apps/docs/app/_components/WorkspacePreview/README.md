# WorkspacePreview

交互预览页使用 Nibferry 的公开布局组件。应用填满父容器，可用 `toolbarStart` 在左栏开关前插入窗口控件。主标题从左栏边界开始，分享和摘要位于主体标题栏末端。右栏标签与操作排列在同一行的右段。两段均使用 `PaneHeader`，调宽或切换全屏时跟随对应栏的实际宽度。

桌面最左侧是由 NavigationRail 和 NavigationRailItem 组成的图标栏。展开时它与项目列表并排。收起项目列表后，仍可从图标栏切换会话、查看摘要或打开文档，点击首页可回到原来的项目列表。窗口内容宽度小于 820px 时隐藏图标栏，分栏布局继续按自身宽度切换。

工具栏右端的按钮打开右栏，可拖动分隔线，再用全屏按钮展开内容。全屏保留左侧导航的显隐状态，退出后恢复原栏宽。窄屏通过左右开关切换当前区域，桌面模式独立保留。

左栏用 ConversationList、ConversationGroup 和 ConversationItem 展示项目与会话。项目可以分别展开，工作区用同一份选择更新条目、标题和摘要。窄屏选择会话后回到主体，桌面在右栏全屏时选择会话会恢复并排布局。

「查看会话摘要」在主体右上角打开 SummaryCard。卡片使用 SummaryGroup 和 SummaryItem 组合项目、侧边聊天及来源。选择来源后，右侧工作区显示对应的本地文档。

右栏标题使用 WorkspaceTabList、WorkspaceTab 和 WorkspaceTabAdd。新标签可打开来源，再次选择已打开的文档会切回对应标签。拖动标签或按 Alt 加左右方向键可排序。关闭当前页优先选中右邻页，末尾页关闭后选中左邻页，最后一页关闭后回到主体。
